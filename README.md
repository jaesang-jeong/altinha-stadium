# ⚽ 알치냐 마라카낭 스타디움 (Altinha Maracanã Stadium) - 원본 화면 맞춤
> **`a.png` 원본(Estádio do Maracanã) 기반의 2D 캔버스 브라질 축구 원바운드 볼 랠리 게임**  
> 모든 해상도(모바일, 태블릿, 와이드스크린 데스크톱)에 맞춰 완벽한 구도와 비율로 자동 정렬되는 최적화 버전입니다.

---

## 🌟 화면 맞춤(Screen-Fit) 주요 개선 사항

### 1. 🏟️ 완벽한 구도 배치 (선수가 관중석에 들어가지 않음)
* **피치 지평선 & 4인 서클의 황금 비율**:
  * 상단 약 38%는 야간 스타디움 관중석, 8열 응원 관중 도트, 대형 전광판, 듀얼 조명탑 라이트 빔, LED 펜스 전광판이 시원하게 자리 잡습니다.
  * 하단 약 62%는 푸른 잔디 피치(Mower-Striped Lawn)로 넓고 쾌적하게 펼쳐집니다.
* **4인 서클의 피치 위 자연스러운 정렬**:
  * 원본(`a.png`)에서 상단 선수(Neymar Jr)가 관중석 4번째 열에 묻히던 현상을 수정하여, **4명 모두(Neymar Jr, Lucas, Vinicius, 나)가 잔디 그라운드 위에 안정적으로 위치**합니다.
  * 중앙선 및 센터 서클, 패스 궤도 링이 4인 선수의 서클 크기에 맞게 정확히 일치하여 정통 축구 중계 화면과 같은 완성도를 선사합니다.

### 2. 📱 모든 기기/해상도 반응형 자동 적응 (Responsive Adaptation)
* **동적 뷰포트 계산 (`calculateScreenFitLayout`)**:
  * 창 크기 변경 및 모바일 세로/가로 회전 시 실시간으로 피치 여백, 선수 간격, 서클 반지름을 비례 계산합니다.
  * 모바일 화면에서도 선수가 양옆으로 잘리지 않으며, 하단 터치 가상 조이스틱과 스킬 버튼이 플레이어 캐릭터를 가리지 않도록 하단 여백을 자동으로 확보합니다.
* **고해상도 Retina / Hi-DPI 디스플레이 지원**:
  * `devicePixelRatio`를 반영하여 캔버스 왜곡이나 흐림 없이 또렷한 고해상도 그래픽을 렌더링합니다.

### 3. 🕹️ 물리 키보드 & 한글 자판 완벽 지원
* 한글 입력기 상태(`ㅇ`, `ㅁ`, `ㅈ`, `ㄴ`, `ㅋ`, `ㅌ`, `ㅊ`)에서도 이동과 스킬이 100% 즉각 반응합니다.
* 물리 키 코드(`e.code: KeyW, KeyA, KeyS, KeyD, KeyZ, KeyX, KeyC, Space`)를 동시 지원합니다.

## 🎮 게임 룰 & 조작법

### ⚽ 알치냐(Altinha) 원바운드 룰
* 공이 공중에 머무는 동안은 **0 바운드 (공중)**.
* 지면에 1회 바운드되는 것까지는 유효 랠리로 인정 (`1 BOUND!`).
* 2회 바운드되거나 선수가 놓치면 랠리 실패 (라이프 1개 차감).

### ⌨️ 조작키

| 조작 | 키보드 (물리키 / 한글 자판 완벽 지원) | 모바일 터치 | 기술 설명 |
| :--- | :--- | :--- | :--- |
| **이동** | `방향키` 또는 `W`, `A`, `S`, `D` (`ㅈ`, `ㅁ`, `ㄴ`, `ㅇ`) | 가상 조이스틱 | 잔디 피치 자유 이동 |
| **인사이드 킥** | `Z` 또는 `J` (`ㅋ`, `ㅓ`) | 노란색 `인사이드` | 안정적인 기본 패스 (1.0x) |
| **바이시클 킥** | `X` 또는 `K` (`ㅌ`, `ㅏ`) | 하늘색 `바이시클` | 화려한 아크로바틱 킥 (1.8x) |
| **라보나 트릭** | `C` 또는 `L` (`ㅊ`, `ㅣ`) | 보라색 `라보나` | 삼바 감각의 꼬아차기 트릭 (1.5x) |
| **다이빙 헤더** | `Space` | 빨간색 `다이빙` | 온몸을 던지는 결정타 (2.4x) |
| **기술 도감** | `H` 또는 `Tab` | 상단 `도감 (H)` 버튼 | 스킬 및 룰 가이드 모달 |
| **배속 조절** | 상단 `0.5x` / `0.8x` / `1.0x` | 상단 배속 버튼 | 초슬로우 / 느림 / 보통 |
