# 🏖️ Altinha_Rio_Beach (알치냐 리우 비치) - 모바일 & PC 크로스 플랫폼

> **브라질 리우데자네이루 이파네마 해변(`b.jpg` & `a.jpg`)의 환상적인 일몰을 배경으로 펼쳐지는 2D 캔버스 아케이드 알치냐(Altinha) 볼 랠리 게임**  
> 모바일 스마트폰(아이폰, 갤럭시), 태블릿(iPad), 데스크톱 PC 등 모든 기기와 해상도에서 터치 및 키보드로 완벽하게 플레이할 수 있습니다.

## 📱 모바일 터치 버전 (Mobile Touch Controls) 주요 기능

### 1. 🕹️ 멀티터치 가상 조이스틱 (Pointer Events & Pointer Capture)
* **멀티터치 완전 분리**:
  * 최신 HTML5 `Pointer Events API`와 `setPointerCapture`를 적용하여, **왼손 엄지로 조이스틱을 잡고 이동하면서 오른손 엄지로 스킬 버튼을 연타해도 조이스틱이 끊기지 않습니다.**
* **방향 지시계 & 삼바 골든 놉**:
  * 상/하/좌/우 4방향 가이드 화살표와 점선 가이드 링, 축구공 마크가 각인된 황금빛 아날로그 조이스틱 놉이 탑재되어 직관적인 360도 이동이 가능합니다.
* **햅틱 진동 피드백 (`navigator.vibrate`)**:
  * 모바일 기기에서 버튼을 터치할 때마다 쾌적한 햅틱 진동과 시각적 눌림 효과가 반응합니다.

### 2. ⚡ 4종 터치 아케이드 스킬 버튼 (오른손 전용 클러스터)
* **인사이드 (Z / J / 1.0x)**: 노란색 테마, 가장 안정적인 지상/점프 패스.
* **바이시클 (X / K / 1.8x)**: 하늘색 테마, 높은 체공 고도의 아크로바틱 킥.
* **라보나 (C / L / 1.5x)**: 보라색 테마, 브라질 삼바 감각의 스핀 꼬아차기 트릭.
* **다이빙 헤더 (Space / 2.4x)**: 장미빛 레드 테마, 온몸을 던지는 슈퍼 결정타.

### 3. 👆 다이렉트 화면 터치 타격 (Direct Tap-to-Kick)
* 스킬 버튼을 누르지 않더라도, **모래사장 화면의 공 주변을 가볍게 탭(Tap)**하면 공의 고도(z)에 맞춰 가장 적절한 스킬(인사이드/바이시클/다이빙)이 자동 발동되어 한 손으로도 캐주얼하게 즐길 수 있습니다.

### 4. 🎛️ 터치 컨트롤 원터치 온/오프 토글
* **상단 HUD 게임패드 버튼 (`#touchToggleBtn`)**: 게임 중 언제든지 터치 컨트롤러를 켜고 끌 수 있습니다.
* **메인 메뉴 모바일 스위치 (`#menuTouchToggleBtn`)**: 시작 전 터치 모드를 자유롭게 설정 가능합니다.
* **키보드 단축키 `M`**: PC에서도 `M` 키를 누르면 즉시 가상 조이스틱을 띄워 마우스로 터치 플레이를 테스트해 볼 수 있습니다.
* **모바일 기기 자동 감지**: 터치스크린 기기나 좁은 모바일 화면 접속 시 자동으로 터치 모드가 활성화됩니다.

## 🌅 해변 배경 (`Altinha_Rio_Beach`) 주요 디자인 특징

### 🏖️ 리우 이파네마 해변(Praia de Ipanema) 노을 풍경 재현 (`b.jpg` 참조)
* **석양 그라디언트 & 황금빛 태양**:
  * 상단 하늘은 붉은 노을빛에서 황금빛 오렌지로 부드럽게 이어지며, 산 뒤편으로 넘어가는 찬란한 황금빛 태양과 대기 광륜(Halo)이 표현됩니다.
* **도이스 이르망스(Morro Dois Irmãos) 쌍봉 바위산**:
  * 리우 해변의 상징인 쌍둥이 화강암 봉우리 실루엣과 석양빛을 받는 산등성이 하이라이트 라인이 구현되었습니다.
* **대서양 바다 & 황금빛 윤슬(Glint)**:
  * 먼바다의 짙은 푸른 수평선과 석양이 바다 위에 비치는 황금빛 반사광(Specular Glint), 해안선을 따라 부드럽게 밀려오는 백색 파도 포말이 펼쳐집니다.
* **모래사장 & 비치 파라솔**:
  * 게임 플레이가 이루어지는 영역은 안정적인 황금빛 모래사장이며, 해변 가장자리에는 리우 해변 특유의 알록달록한 비치 파라솔들이 배치되어 있습니다.
  * 플레이에 방해가 되지 않도록 선수 발밑의 일렁임이나 구름, 중앙을 가로지르는 불필요한 라인을 완전히 배제했습니다.

## 🌟 화면 맞춤(Screen-Fit) 최적화

### 1. ⚽ 안정적인 4인 서클 배치
* **황금 비율 구도**:
  * 상단 약 32~34%는 이파네마 해변의 아름다운 석양, 바다, 도이스 이르망스 산, 전광판이 시원하게 조망됩니다.
  * 하단 약 66~68%는 넓은 모래사장으로 펼쳐지며, **4명의 선수(Neymar Jr, Lucas, Vinicius, 나)가 모래사장 중앙에 완벽하게 정렬**됩니다.
* **동적 뷰포트 계산 (`calculateScreenFitLayout`)**:
  * 모바일 세로(Portrait) 화면에서는 하단 터치 컨트롤러 공간을 자동 계산하여 선수가 조이스틱이나 버튼에 가려지지 않습니다.
  * 모바일 가로(Landscape) 및 태블릿, PC 화면에서도 여백을 균형 있게 배분하여 선수가 화면 밖으로 잘리지 않습니다.

### 2. 📱 모든 기기/해상도 반응형 자동 적응
* 창 크기 변경 및 모바일 세로/가로 회전 시 실시간으로 모래사장 여백, 선수 간격, 서클 반지름을 비례 계산합니다.
* 고해상도 Retina / Hi-DPI 디스플레이(`devicePixelRatio`)를 지원하여 캔버스 왜곡이나 흐림 없이 또렷한 고해상도 그래픽을 렌더링합니다.

### 3. 🕹️ 물리 키보드 & 한글 자판 완벽 지원
* 한글 입력기 상태(`ㅇ`, `ㅁ`, `ㅈ`, `ㄴ`, `ㅋ`, `ㅌ`, `ㅊ`)에서도 이동과 스킬이 100% 즉각 반응합니다.
* 물리 키 코드(`e.code: KeyW, KeyA, KeyS, KeyD, KeyZ, KeyX, KeyC, Space`)를 동시 지원합니다.

## 🎮 게임 룰 & 조작법

### ⚽ 알치냐(Altinha) 원바운드 룰
* 공이 공중에 머무는 동안은 **0 바운드 (공중)**.
* 지면에 1회 바운드되는 것까지는 유효 랠리로 인정 (`1 BOUND!`).
* 2회 바운드되거나 선수가 놓치면 랠리 실패 (라이프 1개 차감).

### ⌨️ 조작키

| 조작 | 키보드 (물리키 / 한글 자판 지원) | 모바일 터치 컨트롤 | 기술 설명 |
| :--- | :--- | :--- | :--- |
| **이동** | `방향키` 또는 `W`, `A`, `S`, `D` (`ㅈ`, `ㅁ`, `ㄴ`, `ㅇ`) | 가상 조이스틱 (360도 아날로그) | 모래사장 자유 이동 |
| **인사이드 킥** | `Z` 또는 `J` (`ㅋ`, `ㅓ`) | 노란색 `인사이드` 버튼 / 화면 탭 | 안정적인 기본 패스 (1.0x) |
| **바이시클 킥** | `X` 또는 `K` (`ㅌ`, `ㅏ`) | 하늘색 `바이시클` 버튼 / 높은 공 화면 탭 | 화려한 아크로바틱 킥 (1.8x) |
| **라보나 트릭** | `C` 또는 `L` (`ㅊ`, `ㅣ`) | 보라색 `라보나` 버튼 | 삼바 감각의 꼬아차기 트릭 (1.5x) |
| **다이빙 헤더** | `Space` | 빨간색 `다이빙` 버튼 / 화면 탭 | 온몸을 던지는 결정타 (2.4x) |
| **터치패드 토글**| `M` 키 | 상단 HUD 게임패드 아이콘 / 메뉴 스위치 | 가상 컨트롤러 ON/OFF |
| **기술 도감** | `H` 또는 `Tab` | 상단 `도감 (H)` 버튼 | 스킬 및 룰 가이드 모달 |
